# @salon-demos/config

Shared tooling presets used by every workspace package.

| Export                                      | Use                                           |
| ------------------------------------------- | --------------------------------------------- |
| `@salon-demos/config/eslint/base`           | ESLint flat config for TS/JS packages         |
| `@salon-demos/config/eslint/next`           | ESLint flat config for Next.js (App Router)   |
| `@salon-demos/config/eslint/react`          | Base + React hooks and jsx-a11y rules         |
| `@salon-demos/config/prettier`              | Prettier options (also used at the repo root) |
| `@salon-demos/config/tsconfig/base.json`    | Strict TypeScript base                        |
| `@salon-demos/config/tsconfig/library.json` | Base + DOM + JSX, for React packages          |
| `@salon-demos/config/tsconfig/nextjs.json`  | Base + Next.js plugin settings                |
